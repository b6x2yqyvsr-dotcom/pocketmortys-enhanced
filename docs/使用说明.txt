================================================================
              口袋莫蒂（Pocket Mortys）加强版
================================================================

游戏已停服。这个包让它继续能玩，并且把以前那些坑全部填掉。


一、装客户端
----------------------------------------------------------------
APK 在   1-客户端/PocketMortys-加强版.apk      （301 MB）

因为签名和官方/社区版不同，必须先卸载旧的再装：

    adb uninstall com.conspiracyrick.pocketmortys
    adb install -g 1-客户端/PocketMortys-加强版.apk

（MuMu 模拟器：把 APK 拖进窗口即可；装之前先在设置里卸载旧版。）


二、开服务端
----------------------------------------------------------------
双击   2-服务端/启动服务器.command     然后**别关那个窗口**。

服务端只做两件事：应答客户端开机的可达性探测，以及处理账号/存档。
资源不需要它——155 个资源包都在 APK 里。


三、然后直接开游戏
----------------------------------------------------------------
不需要 adb push，不需要手动放任何文件。

**首次启动会慢一点（约 1 分钟）**：APK 里内置的一段引导代码会把
     files/AssetBundle.dat      （31,826 字节完整清单）
     files/UnityCache/Shared/   （155 个资源包，约 179 MB）
自动铺好。铺完就进主菜单，以后每次启动都是秒进。

看到进度条卡一下属于正常，那是在写文件，别杀进程。


四、以前那些坑，这个版本修了什么
----------------------------------------------------------------
1. 「无法连接，请检查网络连接。错误：过期资源」
   客户端全新安装时自己建的 AssetBundle.dat 是 226 字节空壳（有版本号、
   没清单），于是判「过期资源」。
   → 现在首启自动铺一份完整清单，不再出现。

2. 一直转圈、Unity 日志停在 "analytics API Initialized"
   → 客户端开机要用不带 UA 的 GET / 做可达性探测，服务端必须**开着且回 200**。
     本包的服务端已实现；探测拿不到响应客户端就永远转圈，这是客户端自身设计。

3. 明明服务端在跑，客户端一个请求都不发
   → APK 的 globalgamemanagers 里 insecureHttpOption 被设成 2（允许明文 HTTP）。
     旧包里这个值被改回了 0，Unity 会在发出请求前就拒掉。

4. 换过 network_security_config 之后游戏启动即崩
   → 那个文件必须是**二进制 XML**。旧包里那份「成品」其实是纯文本，
     塞进去会 Resources$NotFoundException: Corrupt XML binary file。
     现在用 aapt2 现场编译，并且用 aapt2 dump 反解校验过。

5. OneTrust 每帧空引用、多人暂停菜单崩溃、开场剧情/教程挡路
   → libil2cpp.so 里 10 处 arm64 指令补丁全部打好，并且逐个复验。


五、真机 / 别的模拟器要走 Wi-Fi
----------------------------------------------------------------
本 APK 里烧的地址是 10.0.2.2:8080 —— 那是 MuMu 模拟器看到的宿主机。
真机要用电脑的局域网 IP 重新生成：

    cd 3-复现构建工具
    # 1) 先用原始官方 APK 生成带 Java 引导层的基准包
    python3 build_java_layer.py --base 官方.apk --work /tmp/pmbase \
        --manifest ../2-服务端/cdn/Aliases/rat/Android/manifest.json \
        --dat AssetBundle.dat -o /tmp/base-java.apk
    # 2) 再打全部补丁 + 自包含资源
    python3 build_enhanced.py --base /tmp/base-java.apk --variant full \
        --metadata-host 192.168.1.100 --out PocketMortys-加强版-真机.apk

（需要 apktool、JDK、Android SDK build-tools。）
不想重新打包的话，也可以让真机接 USB 后用 adb reverse 走 127.0.0.1：
    adb reverse tcp:8080 tcp:8080
但那个 APK 里的地址也得是 127.0.0.1，所以要重新生成一份。
